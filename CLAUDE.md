# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

**Read `AGENTS.md` first, in full.** It is the provider-neutral rule source and
holds everything that matters here: what `flipauth` is, the commands and test
suites, the architecture, and the conventions. All of it applies to Claude Code
unchanged, so none of it is repeated in this file.

`KANBAN.md` is the only short current-state panel; read it after `AGENTS.md`.
Consult `lessons.md` only when a task hits a past failure mode.

This file is the Claude-side overlay and is deliberately empty of rules. Add one
here only when it genuinely differs for Claude Code; a rule that would apply to
any agent belongs in `AGENTS.md`, and duplicating architecture here would only
create two copies that drift apart.
