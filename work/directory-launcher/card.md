# 独立账号目录与官方 CLI 启动器

## 目标与验收

2026-11-13 用户修正：关闭旧 CLI/daemon，仅在请求终端重开一个会话；同账号也重启（同日再修正：仅换账号时清场，同账号直接再开，见 terminal-switch.md）。
新 daemon 由官方客户端自动启动。此前独立账号目录与官方凭据生命周期设计继续沿用。
每个账号拥有独立可写 home；官方 CLI 是登录、刷新和请求的唯一所有者。
所有入口共用启动计划；默认记录、后续选择和实际运行事实分开；明确切换才替换同服务全部会话。
不需要网关。完整传递终端/PID/参数/stdio/退出码，未知归属拒绝，失败可回读。

本次退役快照复制和直接 quota 路径，原数据不删除、不导入。现有登记表保持兼容。
原测试中已退役功能的行为不再作为验收，改为验证拒绝执行和字节不变；
独立目录、终端传递、进程生命周期、WSL 边界、归属和并发检查保留并扩充。

## 边界

用户已授权 FlipAuth 与 HarnessBase 的环境适配及命名入口部署。
本轮不真实登录、迁移/刷新凭据或查询配额，不触发实际切换或停止既有进程，
不提交、推送或发布。测试使用一次性 HOME/registry、假 CLI 和受控进程索引；
命名入口部署后只回读文件。公开材料不记录私人标签与身份映射。
